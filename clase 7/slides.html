Arreglos: indexado vs. asociativo

Indexado clave numérica automática


$cursos = ["PHP", "Laravel", "MySQL"];

echo $cursos[0]; // PHP
echo $cursos[2]; // MySQL

Asociativo clave string definida por vos


$curso = [
    "nombre"   => "PHP",
    "duracion" => 40,
    "activo"   => true,
];

echo $curso["nombre"];   // PHP
echo $curso["duracion"]; // 40
En arreglos asociativos la clave describe el dato — como columnas de una tabla

Crear, modificar y eliminar claves


$estudiante = [
    "nombre" => "Ana",
    "nota"   => 75,
    "activo" => true,
];

// Modificar un valor
$estudiante["nota"] = 88;

// Agregar una clave nueva
$estudiante["email"] = "ana@correo.com";

// Eliminar una clave
unset($estudiante["activo"]);

// Verificar existencia
isset($estudiante["email"]);             // true
array_key_exists("activo", $estudiante); // false

Recorrer con foreach


$producto = [
    "nombre"    => "Notebook",
    "precio"    => 1200,
    "categoria" => "tecnología",
    "stock"     => 15,
];

// Sin clave
foreach ($producto as $valor) {
    echo $valor . "\n";
}

// Con clave y valor ← más útil
foreach ($producto as $clave => $valor) {
    echo "$clave: $valor\n";
}
// nombre: Notebook
// precio: 1200  ...

Funciones de inspección


$p = ["nombre" => "Luis", "edad" => 22, "ciudad" => "La Paz"];

array_keys($p);   // ["nombre", "edad", "ciudad"]
array_values($p); // ["Luis", 22, "La Paz"]
count($p);        // 3
isset vs array_key_exists
isset() devuelve false si el valor es null
array_key_exists() devuelve true aunque sea null

Colección de registros

Un arreglo donde cada elemento es un arreglo asociativo.
Representa filas de una tabla o respuestas de una API.


$estudiantes = [
    ["nombre" => "Luis",  "nota" => 75, "curso" => "PHP"],
    ["nombre" => "Sara",  "nota" => 92, "curso" => "PHP"],
    ["nombre" => "Pedro", "nota" => 41, "curso" => "Laravel"],
];

// Acceder a un registro específico
echo $estudiantes[1]["nombre"]; // Sara

// Recorrer todos
foreach ($estudiantes as $e) {
    echo $e["nombre"] . ": " . $e["nota"] . "\n";
}
Este es el patrón que usaremos con array_map, array_filter y usort

Funciones

Bloque de código reutilizable que recibe datos y puede devolver un resultado.


function nombreDeLaFuncion(tipo $param): tipoRetorno {
    // cuerpo
    return $resultado;
}
        

function saludar(string $nombre, string $saludo = "Hola"): string {
    return "$saludo, $nombre!";
}

echo saludar("Ana");             // Hola, Ana!
echo saludar("Luis", "Buenas"); // Buenas, Luis!
Los parámetros con valor por defecto deben ir al final de la lista

Tipos declarados (PHP 8)


function calcularPromedio(array $notas, int $decimales = 2): float {
    if (count($notas) === 0) return 0.0;
    return round(array_sum($notas) / count($notas), $decimales);
}

echo calcularPromedio([75, 88, 92]);     // 85.00
echo calcularPromedio([75, 88, 92], 0); // 85
Tipo en parámetroQué acepta
stringTexto
intEntero
floatDecimal
booltrue / false
arrayArreglo
voidNo retorna nada

Por valor vs. por referencia

Por valor copia — original no cambia


function duplicar(int $n): int {
    $n = $n * 2;
    return $n;
}

$x = 5;
$r = duplicar($x);
echo $x; // 5  ← no cambió
echo $r; // 10

Por referencia & original cambia


function duplicarRef(int &$n): void {
    $n = $n * 2;
}

$x = 5;
duplicarRef($x);
echo $x; // 10 ← cambió
Usar referencias con moderación — solo cuando sea la intención explícita

Scope — las variables externas no existen dentro


$impuesto = 0.13;

// ✗ MAL — $impuesto no existe dentro de la función
function precioMal(float $precio): float {
    return $precio * (1 + $impuesto); // Notice: Undefined variable
}

// ✓ BIEN — pasar como parámetro
function precioConImpuesto(float $precio, float $imp = 0.13): float {
    return round($precio * (1 + $imp), 2);
}

echo precioConImpuesto(100);       // 113.00
echo precioConImpuesto(100, 0.16); // 116.00

Arrow functions — fn

Función anónima de una sola expresión. Captura el scope externo automáticamente.


// Función anónima (closure)
$esPar = function(int $n): bool {
    return $n % 2 === 0;
};

// Arrow function equivalente (PHP 7.4+)
$esPar = fn(int $n): bool => $n % 2 === 0;

// Captura variable externa sin "use"
$minimo = 51;
$esAprobado = fn(int $nota): bool => $nota >= $minimo;

echo $esAprobado(75); // true
echo $esAprobado(40); // false
Las arrow functions son ideales para pasar como argumento a array_map, filter y usort

array_map

Aplica una función a cada elemento y retorna un nuevo arreglo.
El original no se modifica.


array_map(callable $fn, array $arr): array
        

$notas = [75, 42, 88, 61, 95];

// Agregar 5 puntos de bonus
$conBonus = array_map(fn($n) => min($n + 5, 100), $notas);
// [80, 47, 93, 66, 100]

// Convertir a string
$etiquetas = array_map(fn($n) => "Nota: $n", $notas);
// ["Nota: 75", "Nota: 42", ...]
Pensalo como: "quiero otro arreglo con cada elemento transformado"

array_map sobre colección de registros


$estudiantes = [
    ["nombre" => "Luis",  "nota" => 75],
    ["nombre" => "Sara",  "nota" => 92],
    ["nombre" => "Pedro", "nota" => 41],
];

// Extraer solo los nombres
$nombres = array_map(fn($e) => $e["nombre"], $estudiantes);
// ["Luis", "Sara", "Pedro"]

// Agregar campo "estado" calculado
$conEstado = array_map(function($e) {
    $e["estado"] = $e["nota"] >= 51 ? "Aprobado" : "Reprobado";
    return $e;
}, $estudiantes);
El arreglo original sigue igual — $conEstado es uno nuevo

array_map — dos arreglos en paralelo


$nombres = ["Ana",  "Luis", "Sara"];
$notas   = [88,     75,     92   ];

$resultados = array_map(
    fn($nombre, $nota) => "$nombre obtuvo $nota puntos",
    $nombres,
    $notas
);

// ["Ana obtuvo 88 puntos",
//  "Luis obtuvo 75 puntos",
//  "Sara obtuvo 92 puntos"]
Cuando se pasan dos arreglos, el callback recibe un elemento de cada uno

array_filter

Retorna un nuevo arreglo con solo los elementos para los que el callback devuelve true.
El original no se modifica.


array_filter(array $arr, callable $fn): array
        

$notas = [75, 42, 88, 61, 95, 50, 73];

$aprobados  = array_filter($notas, fn($n) => $n >= 51);
// [75, 88, 61, 95, 73]

$reprobados = array_filter($notas, fn($n) => $n < 51);
// [42, 50]
Pensalo como: "quiero solo los elementos que cumplen X condición"

⚠️ Las claves originales se preservan


$notas = [75, 42, 88, 61, 95];
//  idx:  0   1   2   3   4

$filtrado = array_filter($notas, fn($n) => $n >= 70);
// [0 => 75,  2 => 88,  4 => 95]
//  ↑ huecos en los índices

// Para reindexar: array_values()
$reindexado = array_values($filtrado);
// [0 => 75,  1 => 88,  2 => 95]
Siempre usá array_values() después de array_filter si necesitás índices consecutivos

array_filter sobre colección de registros


$estudiantes = [
    ["nombre" => "Luis",   "nota" => 75, "estado" => "activo"],
    ["nombre" => "Sara",   "nota" => 92, "estado" => "activo"],
    ["nombre" => "Pedro",  "nota" => 41, "estado" => "activo"],
    ["nombre" => "Camila", "nota" => 88, "estado" => "inactivo"],
];

// Solo activos con nota >= 51
$aprobadosActivos = array_values(array_filter(
    $estudiantes,
    fn($e) => $e["estado"] === "activo" && $e["nota"] >= 51
));
// Luis (75), Sara (92)

array_filter sin callback

Si no se pasa callback, elimina los valores falsy:


// Valores falsy: 0, "", null, false, []
$mezclado = [0, "PHP", false, 42, null, "", "Laravel"];

$limpio = array_values(array_filter($mezclado));
// ["PHP", 42, "Laravel"]
Útil para limpiar arreglos que vienen de formularios o APIs

usort

Ordena el arreglo usando una función de comparación propia.
Modifica el arreglo original.


usort(array &$arr, callable $comparador): bool

El comparador recibe $a y $b y debe retornar:

RetornoSignificado
< 0$a va antes que $b
= 0Son iguales
> 0$b va antes que $a
Pensalo como: "quiero los mismos elementos pero en otro orden"

El operador nave espacial <=>

Devuelve exactamente -1, 0 o 1 según la comparación.


1 <=> 2  // -1  (1 va antes)
2 <=> 2  //  0  (son iguales)
3 <=> 2  //  1  (2 va antes)

// Ascendente
usort($arr, fn($a, $b) => $a <=> $b);

// Descendente — solo invertir $a y $b
usort($arr, fn($a, $b) => $b <=> $a);

usort — ejemplos prácticos


$estudiantes = [
    ["nombre" => "Luis",   "nota" => 75],
    ["nombre" => "Sara",   "nota" => 92],
    ["nombre" => "Pedro",  "nota" => 41],
    ["nombre" => "Camila", "nota" => 88],
];

// Por nota descendente
usort($estudiantes, fn($a, $b) => $b["nota"] <=> $a["nota"]);
// Sara (92), Camila (88), Luis (75), Pedro (41)

// Por nombre alfabético
usort($estudiantes, fn($a, $b) => $a["nombre"] <=> $b["nombre"]);
// Camila, Luis, Pedro, Sara

Criterio compuesto

Si el primer criterio da empate, se aplica el segundo.


// Primero por curso (A→Z), luego por nota (mayor→menor)
usort($estudiantes, function($a, $b) {
    $porCurso = $a["curso"] <=> $b["curso"];
    if ($porCurso !== 0) return $porCurso;
    return $b["nota"] <=> $a["nota"];
});
usort modifica el original. Si necesitás conservar el orden, copiá el arreglo antes:
$copia = $arr; usort($copia, ...);

Las tres funciones — comparativa

Función Pregunta que responde Modifica original
array_map "¿Cómo transformo cada elemento?" No
array_filter "¿Cuáles cumplen la condición?" No
usort "¿En qué orden los quiero?" Sí
array_values() después de array_filter para reindexar

Pipeline: map → filter → sort

El poder real aparece al encadenar las tres funciones.


// PASO 1 — Enriquecer con datos calculados
$con_promedio = array_map(function($e) {
    $e["promedio"] = round(($e["p1"] + $e["p2"] + $e["p3"]) / 3, 1);
    $e["aprobado"] = $e["promedio"] >= 51;
    return $e;
}, $estudiantes);

// PASO 2 — Solo los aprobados
$aprobados = array_values(array_filter(
    $con_promedio,
    fn($e) => $e["aprobado"]
));

// PASO 3 — Ordenar de mayor a menor
usort($aprobados, fn($a, $b) => $b["promedio"] <=> $a["promedio"]);

Pipeline — visualizado

1array_map — agregar campo "promedio" a cada registro
8 estudiantes → 8 estudiantes (con datos nuevos)
↓
2array_filter — solo los que tienen promedio ≥ 51
8 estudiantes → 5 aprobados
↓
3usort — de mayor a menor promedio
5 aprobados → 5 aprobados ordenados (ranking)
