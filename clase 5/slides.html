¿Cómo funciona un formulario?

Navegador
muestra el formulario
→
Usuario completa y hace clic en Enviar
→
Navegador empaqueta:
nombre=Juan&
email=juan@uni.edu
→
PHP lee con
$_POST['nombre']
y responde HTML 

<form action="procesar.php" method="POST">
  <input type="text" name="nombre">
  <input type="email" name="email">
  <button type="submit">Enviar</button>
</form>
            

<?php
// procesar.php
$nombre = $_POST['nombre'];
$email  = $_POST['email'];

echo "Hola, $nombre!";
echo "Tu email: $email";
Clave: El atributo name del input es la clave con la que PHP lo lee en $_POST['...']

Atributos del formulario

action — ¿A dónde van los datos? 


<form>...</form>


<form action="procesar.php">...</form>


<form action="/registro/guardar.php">
  ...
</form>
Si action se omite, el formulario se envía al mismo archivo donde está escrito. Muy útil cuando PHP y HTML van juntos.
method — ¿Cómo viajan? 


<form action="buscar.php" method="GET">
  <input name="q" placeholder="Buscar">
  <button type="submit">Buscar</button>
</form>



<form action="registro.php" method="POST">
  <input name="password" type="password">
  <button type="submit">Entrar</button>
</form>

GET vs POST

GET POST
¿Dónde van los datos? En la URL: ?nombre=Juan En el cuerpo de la petición (invisible)
¿Se ve en el navegador? Sí — barra de direcciones No
¿Contraseñas? NUNCA Sí
¿Límite de tamaño? ~2000 caracteres Prácticamente ilimitado
PHP lo lee con $_GET['campo'] $_POST['campo']
Casos de uso Búsquedas, filtros Login, registros, formularios de datos
Usar GET cuando: el usuario busca o filtra algo, y querés que la URL sea compartible
Usar POST cuando: el usuario envía datos para guardar, o incluye información sensible

$_POST en PHP

HTML — el formulario

<form action="procesar.php" method="POST">

  <input type="text"
         name="nombre"
         placeholder="Tu nombre">

  <input type="email"
         name="email"
         placeholder="tu@email.com">

  <select name="carrera">
    <option value="sistemas">Sistemas</option>
    <option value="civil">Civil</option>
  </select>

  <button type="submit">Enviar</button>
</form>
PHP — procesar.php

<?php
// $nombre lee el campo con name="nombre"
$nombre  = $_POST['nombre'];
$email   = $_POST['email'];
$carrera = $_POST['carrera'];

// Ver todo lo que llegó (para depurar)
print_r($_POST);

// Resultado en pantalla:
// Array (
//   [nombre]  => Juan
//   [email]   => juan@uni.edu
//   [carrera] => sistemas
// )
Regla: el valor de name en el HTML es exactamente la clave que usás en $_POST['...']

¿Llegaron datos o no?

$_POST solo tiene datos cuando alguien envió el formulario. Si alguien abre el archivo PHP directamente, está vacío. 


<?php
// Verificar el método de la petición
if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    // El usuario envió el formulario — procesamos
    $nombre = $_POST['nombre'];
    echo "Hola, $nombre!";

} else {

    // El usuario solo está visitando la página — mostramos el formulario
    echo "Por favor completá el formulario";

}
¿Qué es $_SERVER?

Un array especial de PHP con información sobre la petición HTTP. $_SERVER['REQUEST_METHOD'] dice si fue GET, POST, etc.
Valor por defecto con ??

$nombre = $_POST['nombre'] ?? '';

Si el campo no existe en $_POST, usa '' en lugar de dar error.

Ejemplo completo — mismo archivo

Patrón muy común: el formulario y el PHP que lo procesa están en el mismo archivo. 


<?php
$errores = [];
$exito   = false;
$nombre  = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nombre = trim($_POST['nombre'] ?? '');

    if (empty($nombre)) { $errores[] = "El nombre es obligatorio"; }

    if (empty($errores)) { $exito = true; }
}
?>
<!DOCTYPE html><html lang="es"><body>

<?php if ($exito): ?>
    <p>Bienvenido, <?= htmlspecialchars($nombre, ENT_QUOTES, 'UTF-8') ?>!</p>
    <a href="registro.php">Volver</a>

<?php else: ?>
    <?php foreach ($errores as $e): ?>
        <p style="color:red"><?= htmlspecialchars($e, ENT_QUOTES, 'UTF-8') ?></p>
    <?php endforeach; ?>

    <form action="registro.php" method="POST">
        <input type="text" name="nombre"
               value="<?= htmlspecialchars($nombre, ENT_QUOTES, 'UTF-8') ?>">
        <button type="submit">Registrarse</button>
    </form>
<?php endif; ?>

</body></html>

El flujo en 3 pasos

📋
1. HTML envia
  • action = destino PHP
  • method="POST"
  • Campos con name
  • Botón type="submit"
🐘
2. PHP procesa
  • Lee con $_POST
  • Limpia con trim()
  • Valida con empty()
  • Sanitiza con htmlspecialchars()
🖥️
3. PHP responde
  • Errores → vuelve al formulario
  • Éxito → mensaje de confirmación
  • Valores pre-llenados si hay errores
Este ciclo es la base de toda la web tradicional. Login, registros, comentarios, pedidos — todos funcionan igual.

Complementario fetch básico

La misma idea — enviar datos al servidor — pero sin recargar la página.

PHP — saludo.php (no cambia)

<?php
// PHP funciona igual — no sabe si
// viene de un formulario o de fetch
$nombre = $_GET['nombre'] ?? 'desconocido';
$nombre = htmlspecialchars(trim($nombre),
    ENT_QUOTES, 'UTF-8');

echo "Hola, $nombre!";
JavaScript — fetch en 4 líneas

function saludar() {
  var nombre = document.getElementById('nombre').value;

  fetch('saludo.php?nombre=' + nombre)
    .then(function(respuesta) {
      return respuesta.text();   // leer la respuesta
    })
    .then(function(texto) {
      // mostrar sin recargar
      document.getElementById('resultado').innerHTML = texto;
    });
}
Formulario clásico fetch
¿Recarga la página? Sí, siempre No
¿Necesita JavaScript? No Sí
PHP del lado del servidor Exactamente igual — lee $_GET o $_POST

Resumen de la clase

Lo que vimos hoy
1
<form action="..." method="POST"> envía datos al servidor
2
$_POST['campo'] lee el valor del campo name="campo"
3
trim() + empty() limpian y validan los datos
4
htmlspecialchars() sanitiza antes de mostrar en HTML
5
fetch hace lo mismo sin recargar la página (con JS)
Cheat sheet rápido

// Leer campo POST
$val = trim($_POST['campo'] ?? '');

// Validar
if (empty($val)) { /* error */ }
if (!filter_var($email,
    FILTER_VALIDATE_EMAIL)) { /* error */ }

// Sanitizar para mostrar en HTML
echo htmlspecialchars($val, ENT_QUOTES, 'UTF-8');

// Verificar que se envió el formulario
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // procesar
}
