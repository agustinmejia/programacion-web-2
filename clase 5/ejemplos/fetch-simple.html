Fetch sin recargar la página

Mismo resultado que un formulario, pero la página no se recarga.
Compará con formulario.html para ver la diferencia.

Respuesta de saludo.php

La respuesta aparecerá aquí sin recargar la página

El código JavaScript (abrí las DevTools para verlo en acción) 
// 1. Leer el valor del campo
var nombre = document.getElementById('campo-nombre').value;

// 2. Construir la URL con el nombre como parámetro
//    Resultado: "saludo.php?nombre=Juan"
var url = 'saludo.php?nombre=' + nombre;

// 3. fetch() hace la petición al servidor (es como un formulario GET sin recargar)
fetch(url)
    .then(function(respuesta) {
        // La respuesta llegó — leerla como texto
        return respuesta.text();
    })
    .then(function(texto) {
        // Mostrar el texto en la página
        document.getElementById('texto-respuesta').innerHTML = texto;
    });

// Nota: los .then() son la forma de "esperar" la respuesta del servidor.
// No te preocupes por entenderlos a fondo ahora, lo veremos en la Unidad 3.
