01

Declaración de Variables

¿Qué es una variable? VAR

Una variable es un espacio en memoria donde guardamos información temporal. En PHP todas las variables empiezan con el símbolo $. No necesitas declarar el tipo — PHP lo detecta automáticamente. 

ejemplo.php// Declarar variables en PHP
$nombre   = "Ana García";      // string (texto)
$edad     = 22;             // integer (entero)
$precio   = 19.99;          // float (decimal)
$activo   = true;           // boolean (true/false)
$nulo     = null;           // null (sin valor)

// Mostrar variables
echo "Hola, " . $nombre;
var_dump($edad);             // muestra tipo y valor
02

Tipos de Datos

String TEXTO

Cadena de caracteres. Puede usarse con comillas simples o dobles. Las dobles permiten interpolar variables.

$producto = "Mini hamburguesa";
$precio   = 35;

// Interpolación con comillas dobles
echo "$producto cuesta $$precio";
// → Mini hamburguesa cuesta $35

// Funciones útiles de string
echo strlen($producto);       // longitud: 16
echo strtoupper($producto);   // MINI HAMBURGUESA
echo str_replace("Mini", "Mega", $producto);

Integer y Float NÚMERO

Integer es número entero. Float es número decimal. PHP hace conversiones automáticas entre ellos.

$unidades  = 5;           // int
$precio    = 12.50;       // float
$total     = $unidades * $precio;  // 62.5 (float)

echo number_format($total, 2);  // "62.50"
echo intval($precio);          // 12 (trunca decimales)

Array ARREGLO

Colección de valores. Puede ser indexado (numérico) o asociativo (clave => valor). Muy usado en PHP.

// Array indexado
$colores = ["rojo", "verde", "azul"];
echo $colores[0];   // rojo

// Array asociativo
$alumno = [
    "nombre"  => "Carlos",
    "carrera" => "Sistemas",
    "nota"    => 85
];
echo $alumno["nombre"];   // Carlos
03

Estructura if / else / elseif

¿Para qué sirve? CONTROL

Permite tomar decisiones en el código. "Si se cumple esta condición, haz X; si no, haz Y." Es la estructura más fundamental de cualquier programa. 

$nota = 72;

if ($nota >= 90) {
    echo "Excelente 🏆";
} elseif ($nota >= 70) {
    echo "Aprobado ✅";
} elseif ($nota >= 60) {
    echo "En recuperación ⚠️";
} else {
    echo "Reprobado ❌";
}
// → Aprobado ✅

// Operador ternario (versión corta)
$estado = $nota >= 70 ? "Aprobado" : "Reprobado";
04

Estructura switch

¿Para qué sirve? CONTROL

Ideal cuando una variable puede tomar muchos valores distintos. Más legible que múltiples if/elseif encadenados cuando los casos son exactos.

$dia = "lunes";

switch ($dia) {
    case "lunes":
    case "martes":
    case "miércoles":
        echo "Inicio de semana";
        break;
    case "jueves":
    case "viernes":
        echo "Ya casi es fin de semana";
        break;
    case "sábado":
    case "domingo":
        echo "¡Fin de semana! 🎉";
        break;
    default:
        echo "Día no reconocido";
}
05

Bucle for

¿Para qué sirve? BUCLE

Repite un bloque de código un número conocido de veces. Tiene tres partes: inicio, condición, e incremento.

// Contar del 1 al 5
for ($i = 1; $i <= 5; $i++) {
    echo "Iteración: $i\n";
}

// Tabla de multiplicar del 3
for ($n = 1; $n <= 10; $n++) {
    echo "3 x $n = " . (3 * $n) . "\n";
}

// Recorrer array con índice
$frutas = ["mango", "piña", "papaya"];
for ($i = 0; $i < count($frutas); $i++) {
    echo $frutas[$i] . "\n";
}
06

Bucle while / do-while

¿Para qué sirve? BUCLE

Repite mientras una condición sea verdadera. Útil cuando no sabes cuántas veces se va a repetir. do-while garantiza al menos una ejecución.

// while: suma hasta llegar a 100
$suma    = 0;
$numero  = 1;

while ($suma < 100) {
    $suma += $numero;
    $numero++;
}
echo "Suma: $suma, números usados: $numero";

// do-while: siempre ejecuta al menos una vez
$intentos = 0;
do {
    echo "Intento número: $intentos\n";
    $intentos++;
} while ($intentos < 3);
07

Bucle foreach

¿Para qué sirve? BUCLE

Diseñado específicamente para recorrer arrays. Más limpio y seguro que usar un for con índices. El más usado en PHP para trabajar con listas y datos.

// Array indexado
$platillos = ["hamburguesa", "popcorn", "papas"];

foreach ($platillos as $item) {
    echo "🍔 $item\n";
}

// Array asociativo: clave => valor
$precios = [
    "hamburguesa" => 45,
    "popcorn"     => 30,
    "refresco"    => 20
];

foreach ($precios as $producto => $precio) {
    echo "$producto: $$precio\n";
}
08

Funciones

¿Para qué sirve? FUNCIÓN

Agrupa un bloque de código reutilizable bajo un nombre. Evita repetir código. Puede recibir parámetros y retornar un resultado.

// Declarar una función
function calcularDescuento($precio, $porcentaje) {
    $descuento = $precio * ($porcentaje / 100);
    return $precio - $descuento;
}

// Llamar la función
$precioFinal = calcularDescuento(100, 20);  // 80
echo "Precio con descuento: $$precioFinal";

// Parámetros con valor por defecto
function saludar($nombre, $saludo = "Hola") {
    echo "$saludo, $nombre!";
}

saludar("María");            // Hola, María!
saludar("Luis", "Buenos días");  // Buenos días, Luis!
