¿Qué es PHP?

PHP: Hypertext Preprocessor

Lenguaje que se ejecuta en el servidor.
El navegador solo recibe el HTML resultante.


Navegador → petición HTTP → Servidor
                                ↓
                          PHP procesa .php
                                ↓
Navegador ← HTML generado ← Servidor

Primer archivo PHP


<?php
echo "Hola desde el servidor";
?>
Todo el código PHP va entre <?php y ?>
echo imprime en el HTML generado

Variables


<?php
$nombre   = "Carlos";   // string
$edad     = 21;          // int
$promedio = 8.75;        // float
$aprobado = true;        // bool
$dato     = null;        // null
  • Siempre empiezan con $
  • No se declara el tipo — PHP lo infiere
  • Sensibles a mayúsculas: $Nombre ≠ $nombre

Strings: comillas dobles vs simples


$nombre = "Ana";

// Comillas dobles → interpolan variables
echo "Hola, $nombre";       // Hola, Ana
echo "Hola, {$nombre}!";    // Hola, Ana!

// Comillas simples → literal, sin interpolar
echo 'Hola, $nombre';       // Hola, $nombre

// Concatenación con el punto (.)
echo "Hola, " . $nombre;    // Hola, Ana
En PHP la concatenación usa ., no +

Operadores aritméticos


$a = 10;  $b = 3;

$a + $b   // 13  — suma
$a - $b   // 7   — resta
$a * $b   // 30  — multiplicación
$a / $b   // 3.33 — división
$a % $b   // 1   — módulo (resto)
$a ** $b  // 1000 — potencia

Operadores de comparación


$x = 5;   $y = "5";

$x == $y    // true  — igual en valor (débil)
$x === $y   // false — igual en valor Y tipo ✓ preferir
$x != $y    // false
$x !== $y   // true                           ✓ preferir

$x > 3    // true
$x <= 5   // true
Usar siempre === y !== para evitar sorpresas

Operadores lógicos


$mayor  = ($edad >= 18);   // false
$activo = true;

$mayor && $activo   // false — AND: ambas verdaderas
$mayor || $activo   // true  — OR: al menos una
!$activo            // false — NOT: niega el valor

if / elseif / else


$nota = 75;

if ($nota >= 90) {
    echo "Excelente";
} elseif ($nota >= 70) {
    echo "Aprobado";
} elseif ($nota >= 51) {
    echo "Regular";
} else {
    echo "Reprobado";
}

Operador ternario


// Forma larga
if ($nota >= 51) {
    $estado = "Aprobado";
} else {
    $estado = "Reprobado";
}

// Forma corta — ternario
$estado = ($nota >= 51) ? "Aprobado" : "Reprobado";
Usar solo para condiciones simples — no anidar ternarios

switch


$dia = "lunes";

switch ($dia) {
    case "lunes":
    case "martes":
    case "miércoles":
    case "jueves":
    case "viernes":
        echo "Día laboral";
        break;        // ← sin break, cae al siguiente case
    case "sábado":
    case "domingo":
        echo "Fin de semana";
        break;
    default:
        echo "Día no reconocido";
}

$estado = "activo";

Bucle for


// Cuando sabés cuántas veces repetir
for ($i = 1; $i <= 10; $i++) {
    echo "Iteración $i\n";
}

// Tabla del 3
for ($i = 1; $i <= 10; $i++) {
    echo "3 × $i = " . (3 * $i) . "\n";
}

Estructura: for (inicio; condición; paso)

Bucle while


// Condición al inicio — puede no ejecutarse nunca
$contador = 5;

while ($contador > 0) {
    echo "$contador... ";
    $contador--;
}
echo "¡Ya!";
// 5... 4... 3... 2... 1... ¡Ya!
Si la condición es falsa desde el inicio, el bloque no se ejecuta

Bucle do-while


// Ejecuta al menos una vez
$numero = 100;

do {
    echo "Ejecutado con número = $numero\n";
} while ($numero < 10);

// Se imprime una vez aunque 100 < 10 es false
La condición se evalúa después del bloque

Bucle foreach


$cursos = ["PHP", "Laravel", "MySQL"];

// Solo valor
foreach ($cursos as $curso) {
    echo $curso . "\n";
}

// Índice y valor
foreach ($cursos as $i => $curso) {
    echo "$i: $curso\n";
}
// 0: PHP  1: Laravel  2: MySQL
Es el bucle más usado en PHP — ideal para arreglos

break y continue


for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 === 0) continue; // salta los pares
    if ($i === 9)     break;    // para antes del 9
    echo "$i ";
}
// 1 3 5 7
continueSalta la iteración actual
breakTermina el bucle completamente

Arreglos — Indexado


$frutas = ["manzana", "banana", "naranja"];
//  índice:     0         1         2

echo $frutas[0];    // manzana
echo $frutas[2];    // naranja
echo count($frutas); // 3

$frutas[] = "uva";           // agrega al final
array_push($frutas, "kiwi"); // equivalente
Los índices empiezan en 0

Arreglos — Asociativo


$estudiante = [
    "nombre"  => "María",
    "dni"     => "98765432",
    "nota"    => 88,
    "activo"  => true,
];

echo $estudiante["nombre"];  // María

// Modificar
$estudiante["nota"] = 92;

// Verificar clave
if (isset($estudiante["email"])) {
    echo $estudiante["email"];
}

Arreglos — Multidimensional


$alumnos = [
    ["nombre" => "Luis",  "nota" => 75],
    ["nombre" => "Sara",  "nota" => 90],
    ["nombre" => "Pedro", "nota" => 60],
];

// Acceder a un elemento
echo $alumnos[1]["nombre"];   // Sara

// Recorrer
foreach ($alumnos as $alumno) {
    echo $alumno["nombre"] . ": " . $alumno["nota"] . "\n";
}

Funciones de arreglos


$nums = [5, 2, 8, 1, 9];

count($nums)              // 5
in_array(8, $nums)        // true
min($nums)                // 1
max($nums)                // 9
array_sum($nums)          // 25
sort($nums)               // [1,2,5,8,9] — modifica original
array_reverse($nums)      // devuelve nuevo arreglo

// Para arreglos asociativos:
array_keys($arr)          // devuelve las claves
array_values($arr)        // devuelve los valores
